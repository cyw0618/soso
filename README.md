# 군수집 막내아들 (엔트리 게임)

「재벌집 막내아들」을 패러디한 **엔트리(.ent) 게임**입니다. 무대는 세종시 **조치원**.
할아버지(군수)의 자리를 두고 두 큰아버지와 경쟁하는 막내아들이 되어, 조치원 40곳을 돌며 선거유세를 합니다.
군수가 된 뒤에는 **세종시장 → 대통령**까지 올라가는 커리어 모드가 이어집니다.

**파일:** [`군수집_막내아들.ent`](군수집_막내아들.ent) — 엔트리(playentry.org) 만들기 화면에서 `오프라인 작품 불러오기`로 열면 됩니다.

## 게임 방법

0. 작품을 켜면 제작사 로고 영상(CYW GAMES)이 **0.75배 속도**로 나온 뒤 타이틀로 넘어갑니다 (클릭하거나 스페이스로 건너뛰기).
1. **타이틀 → 이야기 → 조치원 지도.** 유세 장소는 **40곳**입니다. 가운데 지도는 조치원 전체, '시내 확대'를 누르면 시내 15곳이 보여요. 번호 화살표에 마우스를 올리면 장소와 게임 설명이 나오고, 누르면 유세를 시작합니다. 장소마다 **딱 한 번**만 유세할 수 있어요.
2. 장소마다 **장르가 모두 다른 미니게임**(40종)을 합니다. 1~15번은 실제 장소 사진, 16~40번은 일러스트(낮·노을·해 질 녘·밤)가 배경이에요.
3. 점수(0~100)에 따라 **지지율**과 **재화(선거자금)**를 얻습니다. 시작 자금은 **10억 원**입니다.
4. **개표는 언제든!** 지도 오른쪽 '개표하기'를 누르면 바로 개표합니다(40곳을 다 돌면 자동 개표). 지지율 50% 초과 + 지배 자본 지분 50% 초과면 당선.
5. 유세 뒤에는 **돌발상황 64종**(공천 자금 제안, 가짜뉴스, 횡령 의혹, 딥페이크 영상, 조천 범람, 전통시장 화재, 군외 자금 투자 제안, 국비 공모사업 등)이 생길 수 있습니다. 선택지 셋 중 **하나는 반드시 성공하는 안전한 선택**(효과는 작음)이고, 나머지는 성공하면 크게 얻지만 실패하면 잃습니다. 선택지 이름은 일부러 애매하게 써서 **어느 것이 안전한지 알 수 없고**, 화면 속 순서도 매번 섞입니다. 결과는 고른 뒤에만 공개됩니다. 사건 규모는 재산에 비례하고, 현금이 바닥나면 주식이 강제로 팔립니다(반대매매).
6. **작전 본부**에서 재화로 사건을 만들거나(큰아버지 비리 제보, 영상 폭로, 복숭아 나눔 등) 위기를 막을 수 있습니다(위기관리팀, 정보 차단). **회의실**에서는 해외 투자자(미국·일본·중동, 가상 회사)와 협상해 투자금을 받을 수 있어요. 받을 금액과 약속할 수익률을 정해 제안하는데, 투자자가 속으로 정한 최소 수익률보다 낮으면 거절당하고 인내심이 바닥나면 결렬됩니다. 투자금은 바로 들어오지만 유세 6번 뒤에 원금 + 약속한 수익을 갚아야 하고, 갚기 전까지는 빚으로 총자산에서 빠집니다.
7. **조치원 증권거래소**: 국내 주식 15종목, 해외 주식 6종목, 코인 6종(실제 이름, 가격·뉴스는 지어낸 것)이 출렁입니다. 유세를 할 때마다 장 시간이 늘어나요.
8. **「조치원 지배 자본」** (총 1000억): 큰아버지 둘이 처음부터 38%를 쥐고 계속 사 모읍니다. 거래소에서 사거나, **협상 테이블**에서 큰아버지와 어렵게 협상해 사 올 수 있어요.
9. **계열사 15개**: 인수하면 유세 때마다 돈을 벌어 오고, 많을수록 최종 점수가 높아요. 큰아버지들도 빼앗으려 합니다.
10. 재산이 0원이 되면 **파산**으로 끝납니다.
11. **당선하면** 원하는 이름(12글자까지)을 입력해 **랭킹(명예의 전당)**에 올립니다. 랭킹은 기록을 지우지 않고 점수 순서대로 계속 쌓이고(10위씩 쪽을 넘겨 볼 수 있음), 엔트리 *실시간 리스트*에 저장돼서 작품을 껐다 켜도 남아 있습니다.
12. **이어하기**: 엔트리에 로그인한 계정이면 진행 상황이 **자동 저장**됩니다(지도·집무실에 들어올 때, 거래·구매 뒤 5초 안에, 그리고 30초마다). 집무실과 거래소의 '지금 저장' 버튼으로 바로 저장할 수도 있어요. 저장 칸을 **A·B 두 개 번갈아** 쓰고 저장 번호를 붙여서, 한쪽이 깨져도 직전 저장으로 이어집니다. 작품을 나갔다 들어오면, 컴퓨터를 바꿔도(같은 엔트리 계정, 웹에 올린 작품) 타이틀의 '이어하기'로 계속할 수 있어요. 군수 선거에서 지거나 파산하거나 '여기서 끝내기'를 고르면 두 칸 모두 지워지고, '게임 시작'으로 새로 하면 덮어씁니다.

### 커리어 모드: 군수 → 세종시장 → 대통령

1. **군수 취임**: 조치원을 장악하면 '군수 취임(계속하기)'과 '여기서 끝내기(랭킹 등록)' 중에 고릅니다.
2. **집무실**: 45초마다 **결재 서류**가 올라옵니다. 승인·반려에 따라 **평판**이 오르내리고(뒷돈 서류는 승인하면 돈이 생기지만 들킬 수 있어요), 평판은 다음 선거의 시작 지지율과 급여에 영향을 줍니다.
3. **10초마다 수입**: 직위 급여, 정당 후원금, 내 회사 배당, 인수한 기업 수익, 땅 임대료가 실제 시간에 따라 들어옵니다 (화면을 비워도 5분치까지 쌓임).
4. **내 회사**: 초기 자금 **10억**으로 업종(IT 플랫폼·바이오·게임·식품·반도체)을 골라 세웁니다. 가치가 오르내리며 대박도, 부도도 날 수 있어요. 현금의 10/30/50%를 추가 투자하거나 매각할 수 있습니다.
5. **기업 인수**: 실제 국내 기업 **134개**(군수 40 · 시장 54 · 대통령 40). 직위가 오를수록 더 큰 회사(삼성전자, SK하이닉스 등)가 열리고, 인수한 회사는 투자해서 레벨(최대 5)을 올리면 수익이 늘어납니다. 게임 속 가격·수익은 지어낸 값입니다.
6. **부동산 + 정보꾼**: 조치원·세종시·전국 땅 15곳. 정보꾼 셋(정확도 50·75·95%)에게 개발 정보를 사서 호재 전에 사고 악재 전에 팔 수 있어요. 정보는 가짜일 수도 있습니다.
7. **정당**: 시장 선거에 나가려면 창당(10억)하고 당원을 모아 **공천**을 받아야 합니다 (시장: 당원 1만 명, 대통령: 30만 명).
8. **출마**: 세종시장은 **총자산 5000억 + 공천**, 대통령은 **총자산 10조 + 공천**. 세종시 40곳 / 전국 40곳을 돌며 유세하고, **후보 셋 중 지지율 1등**이면 당선입니다. 상대는 제작자가 준 사진의 후보들(1번 더불어국민, 2번 민주의힘 — 패러디 정당 이름).
9. 단계가 오를수록 **작전 본부 가격**이 비싸지고(시장 ×50, 대선 ×1000) 새 기술(지역 방송, 공약집, 전국 TV 광고, 토론 특훈 등)이 열립니다. 「조치원 지배 자본」은 「세종시 지배 자본」(1조) → 「대한민국 지배 자본」(20조)으로 바뀌고, 과반이면 10초마다 배당을 받아요.
10. **특별주**: 시장 선거부터 코인보다 **100배**, 대통령 선거부터 **500배** 출렁이는 특별주가 거래소에 등장합니다.
11. **작전 세력**: 큰손 자금책·리딩방 운영자·찌라시 기자·단타 부대·차명 계좌 관리인·전관 변호사를 직접 골라 세력을 꾸립니다. 장이 열리면 목표 종목이 12초 동안 오르다 8초 동안 무너지니, 미리 사 두고 꼭대기에서 팔아야 해요. 금감원에 걸리면 벌금과 평판·지지율 하락!
12. **계약서 서명**: 회사 설립, 기업 인수, 땅 매입, 창당, 작전 세력, 후보 등록은 계약서 화면에서 마우스로 직접 서명해야 체결됩니다.
13. **수사와 매수**: 세종시장이 되면 **검찰·금감원·노동청·공정거래위원회** 수사가 들어올 수 있어요 (의혹이 많을수록, 직원이 많을수록(노동청), 기업을 많이 인수할수록(공정위) 잘 들어옵니다). '수사 대응'에서 변호사 선임, 기자회견, 몰래 매수(성공 70%), 협조(벌금 내고 마무리) 중에 고르고, 미리 기관을 매수해 두면 3분 동안 수사가 들어오지 않습니다. 걸리면 총자산의 12% 벌금과 평판·지지율 하락!
14. **레버리지·인버스**: 거래소 '레버리지' 탭에서 국내 2X, 국내 인버스 1X, 곱버스 2X, 나스닥 3X, 비트코인 3X·인버스 1X 상품을 사고팔 수 있어요. 지수가 오르면 레버리지가 배로 오르고, 내리면 인버스가 오릅니다.
15. **직원 면접·채용**: 회사를 세우면 전문경영인·전무·상무·부장·차장·팀장·과장·대리·사원을 면접으로 뽑습니다. 지원자마다 경력·급여·숨은 성격(허세, 게으름 등)이 있고, 질문 셋 중 둘(경력 확인, 압박 질문, 실무 테스트)로 알아낼 수 있어요. 직원 능력이 높을수록 회사가 잘 크고 위기를 잘 넘기지만 급여가 10초마다 나갑니다.
16. **엔딩 뒤에도 계속**: 대통령 취임·은퇴·낙선 엔딩을 봐도 '계속 투자하기'로 집무실에 돌아가 투자를 이어 갈 수 있고, 랭킹은 다시 등록하면 내 이전 기록이 새 점수로 바뀝니다.

> 랭킹과 이어하기는 엔트리 **실시간 리스트**(랭킹이름·랭킹점수·저장목록)를 씁니다. 바꾸는 즉시 서버에 저장되기 때문에 창을 닫아도 남습니다(예전의 '공유 리스트'는 값이 서버에 올라가는 때가 정해져 있지 않았어요). 그리고 같은 내용을 **공유 리스트(백업목록)**에도 함께 써 둡니다. 공유 리스트는 작품을 **정지할 때** 서버에 올라가므로, 실시간 연결이 끊겨도 집무실의 **'저장·끝내기'** 버튼(저장 후 작품 정지)이나 정지(■) 버튼으로 끝내면 기록이 남습니다. 불러올 때는 실시간 A·B와 백업 C 가운데 저장 번호가 가장 큰 온전한 것을 고릅니다. 작품이 커서 서버 데이터가 늦게 도착할 수 있으므로, 타이틀에서는 저장을 찾을 때까지 1초마다 다시 찾습니다(최대 60초, 화면에 '서버에서 저장을 찾는 중...' 표시). 엔트리 사이트에 작품을 저장하고 공유해야 서버에 기록이 남아요. 새 버전을 받으면 같은 작품에 덮어써서 저장해야 기록이 이어집니다(새 작품으로 올리면 랭킹이 빈 상태로 시작할 수 있어요).

## 만드는 방법 (빌드)

`.ent` 파일은 파이썬 스크립트로 만듭니다 (블록을 코드로 적어서 엔트리 project.json 과 그림/소리를 묶음).

```bash
pip install pillow numpy
python3 tools/build_game.py          # → 군수집_막내아들.ent
```

| 파일 | 하는 일 |
|---|---|
| `tools/entrygen.py` | 엔트리 블록/오브젝트/장면 → `.ent` (gzip tar: `temp/project.json` + 그림 + 소리) |
| `tools/build_game.py` | 장면 구성: 타이틀, 이야기, 게임 방법, 지도, 유세 결과 |

| `tools/minigames2.py`, `tools/mg_art2.py`, `tools/soko_levels.py` | 미니게임 16~40번(방탈출 포함)과 그림, 징검돌 퍼즐 풀이 확인 |
| `tools/place_art.py` | 새 유세지 25곳의 밤 풍경 배경 그림 |
| `tools/invest.py` | 작전 본부 회의실 (해외 투자자 협상) |

| `tools/gui.py`, `tools/ui_kit.py` | 검정+청색 테마 UI (패널, 버튼, 배너, 아이콘, 효과), 효과음 담당 |
| `tools/make_cover.py`, `tools/toon3d.py` | 표지 합성 (3D 모델 렌더 → 웹툰풍 얼굴, 제목 '군수집') |
