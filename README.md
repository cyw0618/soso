# 군수집 막내아들 (엔트리 게임)

「재벌집 막내아들」을 패러디한 **엔트리(.ent) 게임**입니다. 무대는 세종시 **조치원**.
할아버지(군수)의 자리를 두고 두 큰아버지와 경쟁하는 막내아들이 되어, 조치원 15곳을 돌며 선거유세를 합니다.

**파일:** [`군수집_막내아들.ent`](군수집_막내아들.ent) — 엔트리(playentry.org) 만들기 화면에서 `오프라인 작품 불러오기`로 열면 됩니다.

## 게임 방법

1. **타이틀 → 이야기 → 조치원 지도.** 지도의 화살표 15개가 유세 장소입니다. 장소마다 **딱 한 번**만 유세할 수 있고, 끝난 곳의 화살표는 사라집니다.
2. 장소에 들어가면 **그 장소의 실제 사진이 배경**으로 나오고, 장소마다 **장르가 모두 다른 미니게임**을 합니다.
3. 점수(0~100)에 따라 **지지율**과 **재화(선거자금)**를 얻습니다. 시작 자금은 **10억 원**이고, 100점이면 4억 + 보너스 2억을 받습니다.
4. 유세 뒤에는 **돌발상황 64종**(공천 자금 제안, 가짜뉴스, 횡령 의혹, 딥페이크 영상, 조천 범람, 전통시장 화재, 군외 자금 투자 제안, 국비 공모사업 등)이 생길 수 있습니다. 선택지 셋 중 **하나는 반드시 성공하는 안전한 선택**(효과는 작음)이고, 나머지는 성공하면 크게 얻지만 실패하면 잃습니다. 선택지 이름은 일부러 애매하게 써서 **어느 것이 안전한지 알 수 없고**, 화면 속 순서도 매번 섞입니다. 결과는 고른 뒤에만 공개됩니다. 사건 규모는 재산에 비례하고, 현금이 바닥나면 주식이 강제로 팔립니다(반대매매).
5. **작전 본부**에서 재화로 사건을 만들거나(큰아버지 비리 제보, 영상 폭로, 복숭아 나눔 등) 위기를 막을 수 있습니다(위기관리팀, 정보 차단).
6. **조치원 증권거래소**: 일반 주식 15종목이 장 시간 동안 1초마다 움직이고, 속보/루머 뉴스가 뜹니다. 유세를 할 때마다 장 시간이 늘어납니다.
7. **특별 주식 「조치원 지배 자본」** (총 1000억 = 10만 주): 큰아버지 둘이 처음부터 38%를 쥐고 있고, 유세 때마다 조금씩 더 사 모읍니다. **지분 50% 이상을 모으면 즉시 '조치원 장악' 승리!**
8. 15곳을 모두 돌면 **개표**. 지지율이 두 큰아버지보다 높으면 당선입니다. 재산이 0원이 되면 **파산**으로 끝납니다.
9. **당선하거나 조치원을 장악하면** 원하는 이름(12글자까지)을 입력해 **랭킹(명예의 전당)**에 올립니다. 랭킹은 처음에 비어 있고, 기록을 지우지 않고 점수 순서대로 계속 쌓습니다(10위씩 쪽을 넘겨 볼 수 있음). 랭킹 리스트는 엔트리 *공유 리스트*라서, 작품을 공유하면 모든 사람의 기록이 함께 계속 남습니다.

## 만드는 방법 (빌드)

`.ent` 파일은 파이썬 스크립트로 만듭니다 (블록을 코드로 적어서 엔트리 project.json 과 그림/소리를 묶음).

```bash
pip install pillow numpy
python3 tools/build_game.py          # → 군수집_막내아들.ent
```

| 파일 | 하는 일 |
|---|---|
| `tools/entrygen.py` | 엔트리 블록/오브젝트/장면 → `.ent` (gzip tar: `temp/project.json` + 그림 + 소리) |
| `tools/build_game.py` | 장면 구성: 타이틀, 이야기, 게임 방법, 지도, 유세 결과 |
| `tools/minigames.py`, `tools/mg_art.py` | 미니게임 15종과 그림 |
| `tools/scene_stock.py`, `tools/stock_art.py` | 증권거래소, 조치원 지배 자본 |
| `tools/scenes_more.py` | 돌발상황, 작전 본부, 개표, 조치원 장악, 랭킹, 파산 |
| `tools/gui.py`, `tools/ui_kit.py` | 검정+청색 테마 UI (패널, 버튼, 배너, 아이콘, 효과), 효과음 담당 |
| `tools/make_cover.py`, `tools/toon3d.py` | 표지 합성 (3D 모델 렌더 → 웹툰풍 얼굴, 제목 '군수집') |
| `tools/make_places.py` | 장소 사진 → 배경, 지도 캡처 → 야간 지도 (남색 바탕 + 밝은 도로·흰 글씨로 다시 칠함) |
| `tools/make_sounds.py` | 효과음/배경음 합성 (numpy, mp3 인코딩은 `lameenc` 필요 — 만들어 둔 mp3 가 저장소에 있음) |
| `tools/data.py` | 장소, 주식, 뉴스, 돌발상황, 퀴즈, 대사 |

## 출처

- 인물 사진, 장소 사진 15장, 표지 원본, 3D 모델: 제작자(사용자)가 제공
- 지도: Google 지도 화면 캡처를 게임용으로 편집 (지도 화면 오른쪽 아래에 표기)
- 글꼴: Black Han Sans, Do Hyeon, 나눔고딕, 나눔스퀘어라운드 (SIL OFL), 여기어때 잘난체 (MIT)
- 효과음/배경음: `make_sounds.py`로 새로 합성 (외부 음원 없음)
- 할아버지·큰아버지 대사는 「재벌집 막내아들」 웹툰 속 회장님 말투(표준어 반말, 짧고 단호한 어조)를 살려 이 게임용으로 새로 썼습니다.
- 국내 주식 종목·계열사 이름은 가상입니다. 해외 주식과 코인은 실제 이름을 쓰지만, 게임 속 가격과 뉴스는 모두 지어낸 것입니다.
